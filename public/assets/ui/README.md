# Interface artwork

`wanderer-portrait.webp` is original AI-generated artwork created for ASHENFELL's
loadout panel: a hooded frontier traveller wearing chainmail, worn steel and brass.
It is an optimized 508 × 680 WebP (approximately 57 KB), served locally through
Vite's base URL. It is a decorative character illustration, not a live equipment
preview; the equipment slots remain the source of truth for worn items.

The healing flask is original inline SVG in `src/hud.ts`. Forged-metal textures,
glass resource orbs and ornamental panel frames are implemented locally in
`src/fantasy-ui.css`; they do not require remote images or third-party game assets.
