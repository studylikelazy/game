# ASHENFELL — 灰の境界

中世ヨーロッパ風の森と廃村を舞台にした、2D見下ろし型の脱出ゲームです。ダークファンタジー調の動的ライティングと、アイテムレアリティの発光表現を備えています。ブラウザだけで遊べるソロPvEと、Cloudflare Durable Objectsで同期する最大8人のPvPvEを実装しています。

> 既存作品の画像・音声・キャラクター・名称は使用していません。脱出型ゲームの基本ループを参考にした、オリジナルの小規模プロトタイプです。

### モバイル全画面

タッチ端末の遠征中は、戦場画面の右上にある四隅のアイコン（全画面ボタン）で全画面表示を切り替えられます。

- Fullscreen APIに対応したブラウザ（Androidの Chrome など）では端末の全画面表示を使います。システムの戻る操作やEscで解除すると、通常のレイアウトに戻ります。
- iPhoneのSafariや埋め込みブラウザなど、Fullscreen APIが使えない環境では、アドレスバーや見出し、サイドバーを隠してゲーム領域を画面全体へ広げる表示に切り替えます。
- 全画面表示中も、ノッチ・ホームバーを避けてHUD・操作ボタン・戦域情報を配置します。
- 拠点へ戻ると全画面表示も通常レイアウトも解除されます。
- iPhoneではSafariの「ホーム画面に追加」で開くと、ブラウザのUIを減らして遊べます（`apple-mobile-web-app-capable`）。

### グラフィック品質

「設定 → グラフィック品質」で選択し、「設定を保存」を押すと反映されます。遠征中もメニューの「画質・音量の設定」から変更できます。設定は端末のブラウザに保存されます。

| 画質 | 遠征中の描画上限 | 描画内容 |
| --- | --- | --- |
| 低（軽量） | 30fps | 解像度を抑え、光のにじみ・霧・灰・粒状感を省略 |
| 標準 | 60fps | 中解像度。霧・灰を残し、光のにじみ・粒状感を省略 |
| 高（初期設定） | 60fps | 高解像度。すべての描画効果を使用 |

拠点・ソロ一時停止中はいずれも最大30fpsです。画質を下げても、戦闘の更新頻度・当たり判定・アイテムのレアリティ表示・ダメージ表示は変わりません。「演出を抑える」は画質と独立した設定です。旧セーブの画質は「高」として読み込みます。

## ゲームの流れ

1. 剣または刀を選び、**出撃する**を押す。長弓・矢24本・治療薬3個も支給されます。
2. 木箱、薬草、敵の所持品から物資を回収する。
3. 野盗、狼、騎士と戦う。オンラインでは他の旅人にも攻撃が当たります。
4. 12分以内に3か所ある脱出地点のいずれかで **Eを5秒間長押し**する。
5. 帰還すると戦利品が倉庫に入り、商人への売却や依頼報酬の受け取りができます。

死亡・時間切れ・遠征放棄・オンライン切断では未脱出の戦利品を失います。支給装備と拠点の倉庫は失いません。オンライン参加者は同じ合言葉で同じ戦場に入ります。

## Cloudflareへ公開する（PvPvE対応）

GitHub Pagesとは別の公開方法です。GitHubのコードを使って、Workersへフロントエンドとサーバーをまとめて公開します。

### 手元の端末から公開

```sh
npm ci
npx wrangler login
npm run deploy
```

認証は手元のブラウザで行ってください。認証情報をチャット・GitHubのファイルへ貼らないでください。公開後の `workers.dev` URLはWranglerが表示します。

### Cloudflare管理画面とGitHubを連携する場合

1. Workers & Pagesから新しい **Worker** を作成し、このGitHubリポジトリを選択する。
2. 公開するブランチに `arena/698516c3-game` を指定する（PRをマージした後は `main` も使用可能）。
3. ビルドコマンド：`npm ci && npm run build`
4. デプロイコマンド：`npx wrangler deploy`
5. ルートディレクトリ：リポジトリのルート。

`wrangler.jsonc` が静的アセット、`RAID_ROOMS` Durable Objectバインディング、SQLiteクラスの初回マイグレーションを設定します。Cloudflare側でGitHubへのアクセス許可とWorkers作成権限が必要です。利用料金はCloudflareのプラン・CPU時間・接続時間等に依存します。

**注意:** PvPvE版はCloudflare **Workers + Static Assets** 用です。`dist`だけを静的Pagesへアップロードしても対戦APIは動きません。

## 実装内容と現時点の制約

- **描画:** Canvas 2Dのみで構成したダークファンタジー調の絵作りです。外部の画像素材は使わず、地形・建築・樹木・キャラクター・アイテム・エフェクトをすべて実行時に生成します。
  - **動的ライティング:** 松明・焚き火・ランタン・脱出地点・レアドロップ・旅人自身が光源になり、画面の約22%解像度で解いた光量フィールドを乗算合成します。炎はまたたき、光の届かない場所は灰青色の闇に沈みます。
  - **発光表現:** 光量フィールドを二乗してしきい値処理し、2段階の縮小ボケを加算合成するブルームで、炎・ルーン・レアドロップが周囲に滲みます。
  - **アイテムレアリティ:** 通常・上級・希少・伝説の4段階を世界共通の色で表現し、ドロップ品は地面の発光と垂直のビーム、ミニマップの点、UIの所持品表示で一貫して色分けされます。
  - **地形:** 一度だけ生成してキャッシュする地形ビットマップに、石畳の街道、石造の廃壁、切妻屋根の家屋、井戸、教会のアーチ、墓所、川と葦、樽・木箱・荷車・柵・枯れ枝・骨といった小物を描き込みます。
  - **空気感:** 深度順に並べた人物の重なり、月光のリムライト、漂う灰、霧、ビネット、フィルムグレイン、わずかな色収差で画面をまとめます。
  - **可読性:** 敵の体力バーと名前、被弾の数字、斬撃の軌跡、ダメージサークルは常に最前面に描き、暗い場所でも戦闘状況が読み取れます。
- モバイル対応：タッチ操作UI、攻撃時の自動照準アシスト、画面ドラッグでの照準、レスポンシブレイアウト、セーフエリア（ノッチ）・横向き表示対応、遠征中の全画面表示。
- 遠征中の描画は最大60fps、拠点とソロ一時停止中は最大30fpsに抑えています（90/120Hz端末でも時間累積で間引き）。非表示タブでは描画・クライアント更新を休止し、復帰時に休止時間をまとめて処理しません。オンラインの戦場はサーバー側で進行し続けます。入力とゲーム更新は表示リフレッシュごとに実行します。高DPI端末のCanvasは約200万ピクセルまでに抑え、小型スマホは最大2倍の解像度を保ちます。カメラの外にある地形・敵・効果は描画しません。
- ライティングとブルームは低解像度のバッファで解いてから拡大合成するため、負荷は画面サイズではなく一貫した固定コストに近くなります。「設定 → 演出を抑える」を有効にすると、漂う灰・霧・グレイン・ブルーム・画面揺れ・光のまたたきを停止します（光源の計算は残るため、明暗の読みやすさは変わりません）。
- 剣・刀の近接判定、弓の飛翔体、建物衝突、スタミナ、回避、回復。
- 3種類の敵AI、共有物資、12枠/22kgの背嚢、5秒の脱出待機。
- WebSocketは20Hzで同期し、移動速度・戦闘・命中・物資回収をサーバーが判定。入力値はサーバーで検証します。
- 1戦場最大8接続。空になった部屋は次の参加時にリセット。残り60秒未満の部屋への新規参加は受け付けません。
- 倉庫・銀貨・依頼・設定は **localStorage保存** です。別の端末・ブラウザ・公開ドメインには引き継がれません。
- アカウント認証、サーバー保存の経済、ランク、対戦マッチング、切断復帰、高度な不正対策は未実装です。ローカルセーブは改変可能なので、競技・課金向けの完成版ではありません。
- 戦場の状態はメモリ上で保持します。Worker更新・再起動で進行中の遠征は失われます。
- 敵AIは簡易追跡で、建物を迂回する高度な経路探索はありません。
- 初期装備は無料。商人は戦利品の売却のみで、装備購入・クラフト・保険はまだありません。
- ネットワークゲームの長時間・大規模負荷テストは未実施です。

## 装備システム（PoEを参考にした独自実装）

- 武器は片手剣・刀・斧・槌・短刀・両手剣・弓・弩の8系統・16ベース。物理ダメージ幅、攻撃速度、クリティカル率、射程、スタミナ消費が異なります。
- 頭・胸・手・足・盾・護符・指輪を装備できます。装甲は物理ダメージを軽減、回避は攻撃を確率で無効化、エネルギーシールドはHPより先に消費され、4秒未被弾で回復します。火・冷気・雷耐性の上限は75%です。
- 防具・装飾品は26ベース、武器と合わせて42ベース。新たに決闘士の細剣、斥候の短弓、託宣のフード、鏡面の盾などを追加しています。各装備は既存のスロット別ドロップ抽選に入り、倉庫への保存・装備に対応します。
- 固定ユニークは12種類。「月下の誓い」「落雷の杭」「盲目の託宣」「霧の足跡」を追加しました。素材数・バッグ容量・ドロップ個数は従来どおりです。
- 抽選用のベース・接頭辞・接尾辞・ユニークの検索表を起動時に構築し、アイテム生成のたびに全カタログを走査する処理を削減しています。
- レアリティは白のノーマル（修飾なし）、青のマジック（最大1接頭辞＋1接尾辞）、黄のレア（最大3接頭辞＋3接尾辞）、橙のユニーク（固定修飾）の4段階です。ユニークは必ずしも最強ではありません。
- ベース固有の暗黙修飾と、ランダムな明示修飾を分離。アイテムレベルで修飾の強い段階が解放されます。詳細表示ではT Iが最強です。
- 拠点の「装備とステータス」で装備・支給剣/刀の切替が可能です。倉庫の装備カードから装着、Tabのバックパックから遠征中にも交換できます。カードの「詳細」で全修飾を確認できます。
- 両手剣装備時は弓を使用できず、盾と弓の修飾も無効です。装備交換でHPを回復することはありません。
- 宝箱と敵から装備がドロップし、エリート3体はレア装備を確定で落とします。ドロップの光柱とミニマップ色もレアリティに対応します。
- 生還時は遠征終了時の装備を維持し、バックパックの戦利品を倉庫へ保管します。失敗時は新しく拾った装備を失い、出撃前の装備は保護されます。
- 既存v1セーブの物資・銀貨・進行状況を引き継ぎます。オンラインの装備値はサーバーで再生成しますが、所有権は従来通りローカル保存であり、不正な装備の所有を完全に防ぐ経済サーバーではありません。

## 音響・キャラクター描画

- 最初のクリック／キー操作で音声が有効になります。設定の「効果音」と「環境音」は個別に調節・保存できます。0でミュートになります。
- 環境音：風、低いドローン、焚き火（距離に応じて音量が変化）、遠くの鳥や獣の声。
- 戦闘音：武器の重さ別の振り、弓・弩、肉／金属への命中、被弾、敵種別の攻撃・死亡、回避、足音、回復、回収、脱出。
- 音声は外部作品の録音を使わないWeb Audio合成です。タブが非表示の間は停止し、Web Audio非対応環境では無音でプレイを継続します。
- キャラクターはCanvasによる多層描画です。鎧の金属グラデーション、盾の木目・鋲、布の折り目、武器の刃・柄巻き、狼の毛並みを描き分けます。マジック以上の武器はレアリティ色で発光します。
- 添付のような写実的な3D／プリレンダリング品質とは異なり、既存の2D描画方式を維持した改善です。

### 装備・属性の見た目（追加改善）

- 歩行距離に応じて足と胴体が動き、攻撃時は滑らかな一回の武器スイングになります。「演出を抑える」では歩行の揺れと属性演出の時間変化を停止します。
- 支給された刀も正しい武器種として描画します。胸当ては革／鎖帷子／布で材質を変え、鋼の兜を装備すると頭部の外見が変わります。
- プレイヤーの盾は、実際に装備していて片手近接武器を使用している時だけ表示します。
- 火・冷気・雷の追加ダメージを持つ武器は、最も強い属性の色と小さな炎・氷片・雷光で表現します。矢の軌跡も、その矢が持つダメージ属性を反映します。無属性のマジック以上の武器は従来のレアリティ色を維持します。
- 発光する武器の攻撃は周囲を短く照らします。エネルギーシールド残量がある時には青い輪郭を表示します。これらは見た目のみで、攻撃範囲・ダメージ・当たり判定は変更しません。
- キャラクターは再利用する専用Canvasに3倍解像度で描きます。細かな材質の粒状感と陰影をキャラクターの不透明部分だけに合成し、地面への色漏れを防いでいます。

### 立ち姿・戦闘コントラスト（追加改善）

- 人型の足元をワールド座標の基準にし、胴体を画面上で起こした斜め見下ろしの立ち姿に変更しました。照準で全身が回転せず、前／横／背中の向きと頭の位置、武器を持つ手が変わります。
- 背を向けると胸当てではなく外套の背中を描き、武器は胴体の奥に回ります。狼は従来の四足の見下ろし姿勢を維持します。
- 周囲の暗い環境光をブルーム生成前に抑え、画面全体が灰色に浮く現象を軽減しました。複数のキャラクターが集まった時の過剰な光量も抑えています。
- 倒れた敵の遺体は12秒間残り、最後の4秒で薄れます。遺体の表示は装備回収や戦闘ルールとは独立しています。

### 攻撃音の確認

設定画面の「攻撃音を試す」で、効果音スライダーの現在値を使って剣の音を確認できます。0では意図どおり無音になります。音量を保存せず閉じた場合は、元の設定に戻ります。

攻撃音はアニメーション残量だけでなく成立した攻撃カウンターから検出し、描画フレームを飛ばしても検出を維持します（旧オンラインサーバーではクールダウンのリセット検出にフォールバック）。スタミナ不足・矢切れ・クールダウン中のクリックでは再生しません。自分の攻撃時は環境音を短く下げ、短い音が環境音に埋もれるのを軽減します。

### 剣本体の画像素材への置き換え

片手剣・巨剣を、従来の線とグラデーションだけの描画から、オリジナルの高精細な透過画像素材へ変更しました。刃の面取り・中央の溝・鋼の傷・真鍮の鍔・革巻きの柄を含みます。戦場・装備カード・装備スロット・キャラクターシート・所持品で同じ素材を使います。戦場では片手剣の刃を長くし、読みやすい幅に調整しています。巨剣はさらに大きく描画しますが、当たり判定や射程は変更しません。画像読み込み前／失敗時のみ従来の図形を使用します。

### Dark-fantasy interface

The interface uses locally textured iron panels, weathered brass frames, a new
hooded-traveller portrait, and a shaded glass healing flask to accompany the
textured weapon art. Inventory, equipment, contracts, settings and dialogs share
the same material palette. The portrait is illustrative; actual equipped items
are always shown in the equipment slots.

Combat resources are glass life/stamina orbs (stamina is **not mana**). Their
vertical fill follows the actual current values and gear-modified maxima, with
numeric/accessible progressbar values and a separate energy-shield gauge. Gameplay,
key bindings and equipment rules are unchanged. Compact touch layouts keep the
orbs, hotbar and attack/movement controls separated down to 320px, and UI animation
respects both the saved reduced-motion option and the system preference.
